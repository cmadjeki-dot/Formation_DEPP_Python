# Rapport final — Étude de l’impact du contexte socio-économique sur les performances en lecture des élèves de 6e

## 1. Problématique

L’objectif de cette étude est d’évaluer dans quelle mesure le contexte socio-économique est associé aux performances en lecture des élèves de 6e, et d’estimer l’influence de variables comme le retard scolaire, le type d’établissement et les ressources numériques.

## 2. Méthodologie

La démarche suit la logique d’une production statistique publique :

- construction d’un protocole statistique ;
- simulation d’une base d’élèves ;
- contrôle de qualité ;
- imputation des données manquantes ;
- analyse descriptive ;
- modélisation par régression ;
- analyse psychométrique ;
- restitution décisionnelle.

## 3. Données

La base simulée contient une population d’élèves de 6e avec les variables suivantes :

- sexe ;
- pcs ;
- retard ;
- academie ;
- type_etab ;
- ressources_num ;
- age ;
- score_lecture.

## 4. Résultats attendus

Les résultats attendus sont les suivants :

- les élèves issus de milieux favorisés obtiennent des scores plus élevés ;
- le retard scolaire est associé à des performances plus faibles ;
- le type d’établissement joue un rôle dans les écarts observés ;
- des disparités territoriales sont observées selon les académies.

## 5. Interprétation

Le contexte socio-économique demeure un déterminant majeur des performances en lecture. Les dispositifs d’aide permettent une réduction partielle des écarts, mais des inégalités persistent.

## 6. Recommandations

- renforcer les dispositifs d’accompagnement ciblés ;
- agir en amont sur les élèves en retard ;
- cibler les territoires et établissements les plus fragiles ;
- poursuivre le suivi longitudinal des performances.

## 7. Conclusion

Cette étude illustre la chaîne complète de production statistique d’une évaluation nationale et montre l’importance d’une méthodologie rigoureuse pour produire une aide à la décision fiable.
